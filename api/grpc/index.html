Micropod API

One protobuf-defined Connect service, rendered from the connect-openapi spec. Unary calls are plain POST + JSON, so curl, fetch, and the typed SDKs all hit the same endpoints; streaming RPCs speak the Connect envelope protocol.

Containers

micropod.v1.ContainerService

Container lifecycle, live logs, stats, and exec.

POSTCreateContainerCreate a container without starting it (docker create).POSTDeleteContainerRemove a container. Running containers require force.POSTExecRun a command inside a running container and return its output.POSTGetStatsPoint-in-time resource usage for all running containers.POSTKillContainerSIGKILL a running container.POSTListContainersList all containers.POSTRestartContainerStop then start a container.POSTRunContainerRun a container (docker run).POSTStartContainerStart a stopped container.POSTStopContainerStop a running container (SIGTERM, then SIGKILL after the grace period).POSTStreamContainerLogsLive log stream (server streaming).

Images

micropod.v1.ImageService

Local image inventory and streaming pulls.

POSTDeleteImageRemove an image. Images in use require force.POSTListImagesList all local images.POSTPullImagePull an image, streaming progress events.

Volumes

micropod.v1.VolumeService

Named volumes plus the mount policy applied on container create.

POSTCreateVolumeCreate a named volume.POSTDeleteVolumeRemove a named volume.POSTGetVolumePolicyNamed-volume mount policy applied on container create across every surface (API, shim, app, CLI, MCP).POSTListVolumesList all volumes.POSTSetVolumePolicyReplace the volume mount policy; returns the stored policy.

Networks

micropod.v1.NetworkService

vmnet-backed container networks.

POSTCreateNetworkCreate a container network.POSTDeleteNetworkRemove a container network.POSTListNetworksList all container networks.

Compose

micropod.v1.ComposeService

Compose project lifecycle — run a spec file, tear a project down.

POSTComposeDownTear down a compose project's containers.POSTComposeUpRun a compose spec file, streaming progress lines (server streaming).

System

micropod.v1.SystemService

Runtime snapshot, cleanup usage report, and app updates.

POSTApplyUpdateQuit the app so a downloaded update installs and relaunches. Fails with `failed_precondition` until `UpdateStatus.ready_to_install`.POSTCheckForUpdatesTrigger a background update check in the desktop app (Sparkle). Fails with `unavailable` when the app isn't running.POSTGetSystemRuntime status + disk usage.POSTGetUpdateStatusLast-known updater status from the desktop app.POSTGetUsageWhat a cleanup would reclaim: images and volumes annotated with the containers that reference them.

SandboxContext

com.apple.containerization.sandbox.v3.SandboxContext

The vminitd guest contract (vendored from apple/containerization). Served over vsock port 1024 inside each container VM — not reachable over host HTTP.

POSTCloseProcessStdinClose IO for a given process.POSTConfigureDnsConfigure DNS resolver.POSTConfigureHostsConfigure /etc/hosts.POSTContainerStatisticsGet statistics for containers.POSTCopyCopy a file or directory between the host and guest. Data transfer happens over a dedicated vsock connection; the gRPC stream is used only for control/metadata.POSTCreateProcessCreate a new process inside the container.POSTDeleteProcessDelete an existing process inside the container.POSTFilesystemOperationPerform a filesystem operation on a mounted filesystem.POSTGetenvGet an environment variable from the init process.POSTIpAddrAddAdd an IPv4 address to a network interface.POSTIpLinkSetSet the link state of a network interface.POSTIpRouteAddDefaultAdd an IP route for a network interface.POSTIpRouteAddLinkAdd an IP route for a network interface.POSTKillSend a signal to a process via the PID.POSTKillProcessSend a signal to the provided process.POSTMkdirCreate a new directory inside the sandbox.POSTMountMount a filesystem.POSTProxyVsockProxy a vsock port to a unix domain socket in the guest, or vice versa.POSTResizeProcessResize the tty of a given process. This will error if the process does not have a pty allocated.POSTSetTimeSet time in the guest.POSTSetenvSet an environment variable on the init process.POSTSetupEmulatorSet up an emulator in the guest for a specific binary format.POSTStartProcessStart the provided process.POSTStatStat a path in the guest filesystem.POSTStopVsockProxyStop a vsock proxy to a unix domain socket.POSTSyncPerform the sync syscall.POSTSysctlSet sysctls in the context of the sandbox.POSTUmountUnmount a filesystem.POSTWaitProcessWait for a process to exit and return the exit code.POSTWriteFileWrite data to an existing or new file.
