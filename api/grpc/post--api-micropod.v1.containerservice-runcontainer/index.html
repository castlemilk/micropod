RunContainer

POSThttp://localhost:45454/api/micropod.v1.ContainerService/RunContainer

Run a container (docker run).

Headers

Connect-Protocol-Versionnumberheaderrequired= 1
Connect-Timeout-Msnumberheader= 1

Request body

application/json
RunContainerRequest

Shared request shape for run + create (docker run / docker create).

imagestringrequired= "alpine:3.20"min length 1

Image reference to run, e.g. "alpine:3.20". Pulled if not present locally.

namestring?= "web"

Optional container name; becomes the container ID.

detachboolean= "true"

Return immediately instead of streaming/attaching.

cpusnumber?= "2"double> 0

CPU limit in cores, e.g. 0.5 for half a core.

memorystring?= "512m"

Memory limit, e.g. "512m" or "4g".

envstring[]

Environment variables as KEY=value pairs.

items
string
portsPortMapping[]

Published port mappings (host → container).

items
PortMapping

A published port mapping between host and container.

hostPortinteger= "8080"≤ 65535

Port on the host.

containerPortintegerrequired= 80≤ 65535

Port inside the container.

protocolstring= "tcp"

"tcp" or "udp".

hostIpstring= "127.0.0.1"ipv4

Host interface IP to bind (empty = all interfaces).

volumesstring[]

Bind/volume mounts as "name-or-path:/mount" specs.

items
string
labelsmap<string, string>

Arbitrary metadata labels on the container.

values
string= "string"
initboolean= true

Run an init process as PID 1 to reap zombies.

argumentsstring[]

Command + args override (image entrypoint is used when empty).

items
string

Responses

Success
ContainerRef

Reference to an existing container (or the ID returned by run/create).

idstringrequired= "web"min length 1

Container ID — `container` uses the user-assigned name as the ID.
