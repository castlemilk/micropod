3:T40c,# POST GetMachineStats

`POST http://localhost:45454/api/micropod.v1.MachineService/GetMachineStats`

Resource usage for running machines (all, or one by id), read from the
 backing container's cgroup — nothing runs inside the guest, and a
 stopped machine is never booted to be sampled. CPU % is a delta between
 samples; a machine with no recent baseline is sampled twice ~0.5 s
 apart so a one-shot call still reports a real figure.

## Request

```json
{
  "id": "ci-alpine"
}
```

## Responses

```json
{
  "machines": [
    {
      "id": "ci-alpine",
      "containerId": "ci-alpine-2553d3",

      "blockWriteBytes": "1048576",
      "pids": "13"

  "sampledAt": "2026-01-15T10:30:00Z"
}
```
