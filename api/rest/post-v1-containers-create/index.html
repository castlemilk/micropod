Containers

Create a container without starting it.

POSThttp://localhost:45454/v1/containers/create

Request body

RunContainerRequest
imagestringrequired= "alpine:3.20"

Image reference to run (docker pull if absent).

namestring?= "web"

Optional container name.

detachboolean= true

Return immediately instead of streaming.

cpusnumber?= 0.5double

CPU limit, e.g. 0.5.

memorystring?= "512m"

Memory limit, e.g. "512m".

envstring[]

KEY=value pairs.

items
string= "string"
portsPortSpec[]

Published port mappings.

items
PortSpec
hostPortinteger= 8080
containerPortinteger= 80
protocolstring= "tcp"
hostIPstring?= "0.0.0.0"
volumesstring[]

name-or-path:/mount specs.

items
string= "string"
labelsmap<string, string>

Arbitrary metadata labels.

values
string= "string"
initboolean= true

Run an init process as PID 1.

argumentsstring[]

Command + args override.

items
string= "string"

Responses

Created (not started)
ContainerRef

Reference to an existing container (or the ID returned by run/create).

idstringrequired= "9f2e4a1b3c7d"min length 1

Container ID — `container` uses the user-assigned name as the ID.
