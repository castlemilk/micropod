Generated clients

Client SDKs

Three languages, one contract. Each SDK is generated from proto/micropod/v1 and wraps the raw stubs with a resiliency + instrumentation chain: retry on transient codes, per-call deadlines, W3C trace propagation, and OpenTelemetry metrics.

Retry

Unary calls retry on transient codes with exponential backoff and jitter. Streams are never replayed mid-flight.

Timeouts

A default per-call deadline applies when the caller set none — it never widens an earlier deadline.

Tracing

W3C traceparent propagation on every call. Go + TS emit OpenTelemetry spans and metrics; Swift emits signpost intervals.

Retryable codes

The default policy retries these Connect codes — everything else fails fast. Override via each SDK's policy type.

unavailabletransient transport state — safe to retry
deadline_exceededserver missed its deadline — retry with care
resource_exhaustedrate limit / quota — back off and retry
abortedconcurrency conflict — safe to retry

Go

github.com/castlemilk/micropod/sdk/go

connect-go generated stubs plus a configured client: unary retry on transient codes, per-call deadlines, and otelconnect instrumentation.

Install

1go get github.com/castlemilk/micropod/sdk/go@sdk/go/v0.7.0

Quickstart

1234567891011121314import (
    "connectrpc.com/connect"
    micropod "github.com/castlemilk/micropod/sdk/go"
    micropodv1 "github.com/castlemilk/micropod/sdk/go/gen/micropod/v1"
)

client := micropod.NewClient("http://localhost:45454",
    micropod.WithRetry(micropod.DefaultRetryPolicy()),
    micropod.WithTimeout(30*time.Second),
    micropod.WithOTel(), // global providers, or WithTracerProvider(...)
)

resp, err := client.ListContainers(ctx,
    connect.NewRequest(&micropodv1.Empty{}))

Instrumentation — WithOTel() wraps every call in connectrpc.com/otelconnect — a CLIENT span per RPC (rpc.system, rpc.service, rpc.method), duration histogram + call counter, and W3C traceparent propagation. Pass WithTracerProvider/WithMeterProvider to bypass the globals.

TypeScript

@micropod/sdk

protobuf-es v2 messages + connect-es client. Fetch transport — runs on Node 18+, browsers, and edge runtimes.

Install

1npm install @micropod/sdk

Quickstart

1234567891011121314import { createMicropodClient } from "@micropod/sdk";

const client = createMicropodClient("http://localhost:45454", {
  retry: { maxAttempts: 3 },
  timeoutMs: 10_000,
  otel: true, // or { tracer, meter }
});

const { containers } = await client.listContainers({});

// Streaming is an AsyncIterable — retry never replays it.
for await (const line of client.pullImage({ image: "alpine:3.20" })) {
  console.log(line.status);
}

Instrumentation — otel: true emits a CLIENT span per call, injects the W3C traceparent header, and records micropod.client.duration + micropod.client.calls on the global meter. Streaming calls hold the span open until the stream terminates.

Swift

MicropodSDK

SwiftProtobuf messages + a dependency-light Connect transport over URLSession. The MicropodClient facade covers all 19 MicropodService RPCs.

Install

1.package(url: "https://github.com/castlemilk/micropod", from: "0.7.0")

Quickstart

1234567891011import MicropodSDK

let client = MicropodClient(baseURL: URL(string: "http://localhost:45454")!)
let snapshot = try await client.system()

let ref = try await client.run(.with { $0.image = "alpine:3.20" })

// Server-streaming endpoints return AsyncThrowingStream.
for try await chunk in client.streamLogs(.with { $0.id = ref.id }) {
    print(String(data: chunk.data, encoding: .utf8) ?? "")
}

Instrumentation — TracingInterceptor injects a W3C traceparent header and records an OSSignposter interval per RPC (com.micropod.sdk / rpc) — visible in Instruments. Supply a TraceContextProvider bridging your OTel span to join a real distributed trace.

Versioning & regeneration

SDKs track the daemon version. Go is tagged sdk/go/v*, the TypeScript package ships as a tarball asset on each GitHub release, and Swift consumers pin the repo tag. Generated code refreshes via scripts/gen-sdk.sh — CI fails if proto/ and sdk/ drift.
