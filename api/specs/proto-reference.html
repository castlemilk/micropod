MicropodService

The Micropod management API: container/image/volume/network operations on

the Apple `container` runtime, served by the connect-go API server and

consumable from any connect client (Go, Swift, TS, …).

Method NameRequest TypeResponse TypeDescription
GetSystem Empty SystemSnapshot

Runtime status + disk usage.
ListContainers Empty ListContainersResponse

List all containers.
RunContainer RunContainerRequest ContainerRef

Run a container (docker run).
CreateContainer RunContainerRequest ContainerRef

Create a container without starting it (docker create).
StartContainer ContainerRef Empty

StopContainer ContainerRef Empty

RestartContainer ContainerRef Empty

KillContainer ContainerRef Empty

DeleteContainer DeleteContainerRequest Empty

StreamContainerLogs StreamLogsRequest LogChunk stream

Live log stream (server streaming).
ListImages Empty ListImagesResponse

PullImage PullImageRequest ProgressLine stream

Pull an image, streaming progress events.
DeleteImage DeleteImageRequest Empty

ListVolumes Empty ListVolumesResponse

CreateVolume CreateVolumeRequest Empty

DeleteVolume DeleteVolumeRequest Empty

ListNetworks Empty ListNetworksResponse

CreateNetwork CreateNetworkRequest Empty

DeleteNetwork DeleteNetworkRequest Empty

GetStats GetStatsRequest GetStatsResponse

Exec ExecRequest ExecResponse

ComposeService

A single service of a compose spec, mapped onto `container run` capabilities.

Fields the Apple runtime cannot express (e.g. privileged) are still parsed

so the UI can show them as unsupported rather than silently dropping them.

Build stage target / platform for `build:` sections.

`build.no_cache` / `build.pull` passthrough.

Compose profiles; the service only runs when an enabled profile matches.

Image pull policy: "always" forces a pull, anything else pulls only when the image is not present locally (docker's default "missing").
