## Reading the measurements

Both timed fixtures ran on macOS/arm64 with Go 1.27.2. DNS used eight order-balanced blocks with 50,000 operations per arm and cell. The builds returned identical bytes for 60 ordinary cases each and passed the frame-budget checks. HTTP used 16 order-balanced pairs and 200 scored requests per arm per block over a single warmed in-process connection. Scored durations, timing order and bootstrap estimates are in the raw receipts. Guest socket latency remains open for both experiments.

The five VM analyses replay existing inputs. The request-phase calculation removes time from individual requests before computing each percentile. It holds every other recorded duration fixed. The macvlan analysis uses ranked streams within each arm and retains each cohort separately. The fq and preemption replays retain every first attempt and give all-attempt guardrail denominators. Guardrail-conditioned subsets describe historical outcomes. They do not estimate a prospective treatment effect.

The three verifier experiments used positive controls and single-variable mismatches. Each receipt records rejected and accepted cases. The combined offline validation run passed 41 Python tests and six native Go encoder tests. The full Git revisions and SHA-256s for each result are in the linked ticket receipts. All changes and raw artifacts were kept in the local performance checkout.
