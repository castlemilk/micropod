The two virtio experiments independently changed different negotiated bits and shared five control observations. Each had only one jointly clean pair. The GSO arm order was sequential and the controls were dirty. The RTO subgroups were defined retrospectively using control timeout counts. Whole-invocation CPU divided by scored payload GiB for BBR and CPU per uplink-qdisc GiB for splice use different denominators. Neither result quantifies peer performance.

The sender-buffer experiment was counted once from the preceding Linux workspace. That workspace verified its raw first attempts. This Mac checkout carries its verified issue receipt. The other nine reports are available locally with pinned fixtures or archived input hashes.
