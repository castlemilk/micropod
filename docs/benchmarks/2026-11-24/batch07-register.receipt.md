Five Darwin host-only experiments and five pinned Linux source/fixture experiments narrowed the queue diagnosis. In the virtio transmit fixture, enabling TX NAPI made the same configured byte limit charge outgoing buffers and stop the queue. With the other TX mode the queued-byte counter stayed at zero as the ring accepted more data. On Darwin the unsent-data setting suppressed writable notifications, yet sockets still accepted eager writes. These two findings make the active queue mode, charged bytes and receiver progress relevant to the same VM trace.
