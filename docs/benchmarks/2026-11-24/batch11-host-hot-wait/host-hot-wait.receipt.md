**Guardrails and uncertainty.** All six first attempts in each arm were clean. All 32 streams made progress, all 1,440 fresh arrivals per arm completed, and both arms had zero client errors or reopens. Five of six control and six of six candidate attempts met the 75 ms fresh-p95 guardrail. The control miss measured 84.60 ms. Across the six windows the control and candidate delivered 168,668,373,096 and 175,412,391,776 application bytes, respectively. The host-wide `lo0` input-queue drop counter rose by 3,282 and 3,299, respectively, with zero interface input/output errors. These deltas include other host traffic. Per-flow packet drops were unavailable. Percentile rows describe medians of round percentiles. Intervals enumerate the 46,656 ordered resamples of six paired blocks.

**Fixed fixture.** Gamma-128GB, Darwin arm64/macOS 26.5.1, host-only IPv4 loopback on both legs. Same host, serial dispatch relay, Go HTTP service process, Go client, payload, listener layout and socket settings. Separate fresh relay process per arm, same persistent service. A 256 KiB relay read buffer and a 128-event dispatch turn were unchanged. After a ≥64 KiB read the relay permits up to four further drains within the same nominal 200 µs budget. The sole code change was the `WAIT_NS` compile-time value. Both binaries and the server passed marker and 8 MiB payload-hash checks. The original client checked service markers and exact 8 MiB response lengths while measuring 32 continuous streams for six seconds, and scheduled one fresh connection every 25 ms. All first-attempt raw outputs and order are saved. Three blocks had each arm first. Process cost and host interface counters span the complete client invocation, including warmup and drain; scored bulk bytes provide the denominator.

**Observed host load.** The strict pre-start check measured 77.46% idle, below the 90% stock pilot gate. Before any timed attempt, this suite was explicitly designated an observed-load diagnostic. Pre-arm idle samples ranged from 4.58% to 72.00%; none met 90%. Disk stayed above the selected local 60 GiB floor at every sample, minimum 288.22 GiB. This is one local relay comparison. It supplies no qualified VM throughput or OrbStack result.
