# Published TCP under 32-container CI load on Gamma

Each engine ran 32 persistent HTTP services and 32 disposable CI containers in a four-vCPU, 4 GiB Linux VM. The standard workload admitted four CPU-heavy build steps at once. A second workload admitted eight on the same four vCPUs. Both engines used the same Linux image, source revisions, 8 MiB response bodies, 32-stream Mac client and 240 fresh connections per window. Each four-block file and memory comparison rotated both engines and both response types through every temporal position. A median paired lead compares Micropod with OrbStack within each block. The case medians below are independently rounded. [Workload](kernel_ci.py) · [Receipt verifier](published_link_results.py)
