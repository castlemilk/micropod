Micropod’s macOS app and menu bar now share a redesigned workspace for containers and microVMs.

- Search, filter and group workloads, with responsive inspectors for logs, metrics, files and terminal sessions.
- Consistent light/dark headers, cards, status labels, resource metrics and cache meters, with a refreshed app identity and original operational icons across all 14 workspaces.
- Compact sheets, wrapping long values and adaptive controls keep primary actions accessible as windows resize. The native preview matrix covers 49 surfaces and 129 responsive renders.
- Menu-bar workload shortcuts, measured guest resources and separate cache budgets.
- Inspect retained build contexts and manage package-cache Keep and reviewed cleanup with active-mount protection.
- Cached inventories, lazy rendering, bounded output and visibility-aware polling reduce unnecessary UI work.
- Live log updates arrive promptly while producers keep their pipes open, with bounded buffering and final-output preservation.
- Improved command-palette keyboard focus and fresh machine/cache state after actions.
- Includes the latest storage-location and drive-picker improvements, Apple container compatibility fixes and API error mapping.

The source includes the design tokens, editable SVG icons, light/dark component sheets, native preview gallery and reproducible UI performance observations. A design-kit archive is also attached to this release.

Requires macOS 26 or later. Missing guest-resource readings remain unavailable; sampled CPU values represent consumed cores. Cache telemetry distinguishes retained build content from package chunks.
