Why Micropod

Everything Docker Desktop Does.
None of the tax.

Micropod is a native SwiftUI app built directly on Apple's container runtime — lightweight per-container VMs instead of one heavyweight Linux VM squatting on your RAM.

seconds, not minutes

Native speed

Apple's runtime boots lightweight VMs per container. A postgres compose stack is up in ~3–4 seconds. No Docker Desktop VM warming up, no daemon tax on your battery.

docker-compose.yml in

Compose, translated

The runtime has no native compose — Micropod translates your docker-compose.yml into a reviewable plan: networks, named volumes, builds, dependency-ordered starts, and real healthcheck-based readiness.

5 s sampling

Live stats & charts

Per-container CPU, memory, network I/O, and disk — with rolling charts on the dashboard and a sortable, filterable containers table with a responsive column layout.

real PTY

Terminal, logs & files

An interactive terminal with real job control (setsid + TIOCSCTTY via a tiny C shim), streaming logs with search, and a file explorer that copies files in and out of containers.

menu bar tray

Always in the menu bar

Running count and live CPU at a glance, a tray panel with per-container stats and quick actions, runtime auto-recovery if the daemon ever stops, and native notifications for pulls and builds.

MCP + Connect API

Built for agents

A built-in MCP server (STDIO JSON-RPC) lets Claude and other agents list, run, stop, and inspect containers — plus a Connect/gRPC-compatible HTTP API with Prometheus-style metrics.

Getting started

Running in Three Steps

01

Install Apple's runtime

Micropod manages everything: it detects the container CLI, starts the daemon, and installs the recommended kernel automatically — and keeps the runtime running for you.

02

Pull or compose

Pull an image with live progress, or drop in a docker-compose.yml and review the translated plan before anything starts.

03

Manage everything

Logs, stats charts, a real terminal, file copy, builds, volumes, and networks — from the window or the menu bar. ⌘K opens the command palette.
